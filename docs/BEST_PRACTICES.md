# 10 Best Practices in Basic English

1. Use microservices so each part of the system has one clear job.
2. Use a message queue so sensor data is not lost when traffic is high.
3. Keep secrets like passwords in Key Vault, not inside code.
4. Add health check endpoints for all important services.
5. Use Docker for every service so the app runs the same everywhere.
6. Use Kubernetes resource limits to avoid wasting cloud cost.
7. Store time-based sensor data with proper timestamp indexes.
8. Use CI/CD pipeline so build and deployment are automatic.
9. Monitor logs, errors, CPU, memory, and API response time.
10. Set Azure budget alerts so cloud cost does not go out of control.
